Manual Testing & Test Management – Azure DevOps

In addition to UI automation, this project demonstrates structured manual testing and test management practices using Microsoft Azure DevOps.

### Requirements Management
- Created an Epic to define the overall testing scope.
- Developed User Stories covering Login, Dashboard, and Admin modules.
- Documented functional requirements and acceptance criteria using Given/When/Then format.

### Test Case Design
- Created detailed manual test cases linked to application requirements.
- Designed positive, negative, and UI validation scenarios.
- Documented preconditions, step-by-step test actions, and expected results.
- Organized test coverage across functional modules.

### Test Management

- Used Azure DevOps to manage testing work items and requirements traceability.
- Organized test cases for functional and regression testing.
- Used Azure DevOps work item relationships to maintain alignment between requirements and testing activities.
